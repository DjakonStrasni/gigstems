# docs/

Prateća dokumentacija za GigLab, van glavnog CLAUDE.md (koji ostaje u root-u repozitorijuma jer
ga Claude Code automatski učitava odatle).

- `changelog/` — istorija razvoja po verziji (kao "whats new" fajlovi u gigrek repou).
- `algorithms/` — razrađene odluke/algoritmi za buduće funkcije, pre nego što se kod piše.
- `coding-rules/` — pravila procesa/konvencije za rad na ovom kodu.

Ovi folderi su trenutno prazni — spremni da prime materijale kad budu poslati.
